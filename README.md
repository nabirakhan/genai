# When Does a GAN Help?

**Comparing GAN-generated retinal images against simple fixes for rare severe diabetic retinopathy grades.**
AI4009 Generative AI course project, FAST-NUCES Karachi, Fall 2026. Nabira Khan (23K-0914). Instructor: Dr. Usman Ali.

Severe diabetic retinopathy (grades 3 and 4) is rare in public training data, so classifiers miss
exactly the cases that need urgent referral. This project fine-tunes a **class-conditional
StyleGAN2-ADA** on APTOS 2019 and asks whether adding its grade-3/4 images to classifier training
beats cheap fixes (class weights, oversampling, classical augmentation, RandAugment + mixup), how
the answer changes with the amount of real rare-grade data (10/25/50/100%) and the synthetic ratio
(0.5x/1x/2x), and whether any gain survives an external test set (IDRiD). A negative result is a valid result.

## Layout

| path | what |
|---|---|
| `src/data/` | APTOS download, fundus crop to 256px, duplicate removal (vessel-pattern correlation), stratified split + nested fractions, uint8 cache, stylegan3 zips, Kaggle dataset upload |
| `src/classify/` | EfficientNet-B0 classifier: 6 conditions, `train.py` (resumable), `queue.py` (84 runs) |
| `src/gan/` | generation, per-class FID/KID, synthetic-image metadata/watermark, import from Kaggle |
| `src/analysis/` | tables, bootstrap CIs, learning curves, fraction x ratio map, memorisation check, RPS, Grad-CAM |
| `notebooks/` | Kaggle notebooks (generated by `build_notebooks.py`): data prep, GAN queue (settings in `kaggle_session.json`), evaluation + generation |
| `third_party/stylegan3` | NVlabs/stylegan3 submodule (pinned) + `patches/` (shape-tolerant resume, ADA p restore), see `PATCHES.md` |
| `api/` | FastAPI inference service (HF Space, CPU) for the demo |
| `web/` | React + TypeScript frontend (Vercel) |
| `splits/`, `results/` | tracked CSVs: dedup list and split (image ids only, no APTOS labels), metrics per run, predictions, tables, figures |
| `LAB_RUNBOOK.md` | step-by-step runbook for the lab PC (data + 84 classifier runs) |

Data is never committed; it lives under `GENAI_DATA` (default `C:\genai-data`).

## Setup

```powershell
git clone --recurse-submodules https://github.com/nabirakhan/genai && cd genai
uv venv .venv --python 3.11 && .venv\Scripts\activate
uv pip install -r requirements-lab.txt        # CUDA torch; on a CPU machine use --index-url https://download.pytorch.org/whl/cpu
uv pip install -e ".[api,dev]"
python scripts/apply_patches.py
python tests/smoke_synthetic.py               # CPU end-to-end test on fake images (~2 min)
```
On a Windows machine where `python` is the Microsoft Store alias, use `py` or `.venv\Scripts\python.exe` instead.

## Pipeline

```
python -m src.pipeline status                 # S0..S15 with DONE/PARTIAL/TODO
# Kaggle: notebooks/kaggle_data_prep.ipynb (dedup, split, GAN zips) -> commit its splits/*.csv
python -m src.data.download_aptos && python -m src.data.prepare_images && python -m src.data.split   # split: verify only
python -m src.data.cache
python -m src.classify.queue                  # 84 runs, skips finished ones, resumable
# Kaggle: kaggle_gan_train.ipynb, one ~10 h version per session (src/gan/kaggle_train.py queue: f100 -> f010 -> f010-noaug -> f025 -> f050), then kaggle_gan_eval.ipynb
python -m src.gan.import_synth downloads/synth_f*.zip
python -m src.analysis.aggregate && python -m src.analysis.bootstrap && python -m src.analysis.plots
```

## Design (locked)

Generator: StyleGAN2-ADA (`stylegan3 --cfg=stylegan2 --cond=1`), 256 px, fine-tuned from the FFHQ-256
checkpoint with a newly initialised class embedding, one GAN per fraction, trained only on that fraction's
train split. Classifier conditions: (1) none, (2) class weights, (3) oversampling, (4) classical aug,
(5) RandAugment + mixup, (6) = (5) + GAN grade-3/4 images at 1x (0.5x and 2x at 10% and 100%). 3 seeds,
84 runs. Metrics: macro F1, quadratic weighted kappa, recall for grades 3/4 on the APTOS test split and
IDRiD. GAN: FID/KID (rough indicators), visual check, nearest-neighbour memorisation, Retinal
Pigmentation Score on real vs generated. All synthetic images carry `Synthetic=true` metadata and a
visible SYNTHETIC label wherever they are displayed.
